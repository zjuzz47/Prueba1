
# 🎯 Adivina el Número

Un juego sencillo e interactivo creado con HTML, CSS y JavaScript.

## 🎮 Cómo jugar

1. El juego genera un número aleatorio del 1 al 20.
2. Escribe tu intento en el campo de texto.
3. Recibe una pista para saber si el número secreto es más alto o más bajo.
4. Encuentra el número para ganar.
5. Pulsa "Nueva partida" para volver a jugar.

## 🛠️ Tecnologías

- HTML5: estructura del juego.
- CSS3: diseño adaptable a móviles y computadoras.
- JavaScript: lógica, validaciones e intentos.

## 🚀 Ejecutar el juego

Descarga o clona este repositorio y abre `index.html` en tu navegador.

No requiere instalaciones, servidor ni conexión a internet.

## 🌐 Publicar en GitHub Pages

1. Sube los cuatro archivos al repositorio.
2. Entra en Settings.
3. Abre Pages.
4. En Build and deployment, selecciona Deploy from a branch.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Pulsa Save.

Cuando GitHub termine de publicar el sitio, mostrará el enlace de tu juego en la sección Pages.
